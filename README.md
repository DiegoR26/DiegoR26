  # En Taro Tassadar!

I'm **Diego**, a Brazilian developer focused on building practical software, automation tools, and backend systems.

I currently work mainly with **C# and .NET**, while also using **Python** and **JavaScript** when they are the right tools for the job.

My background is in the fiscal and accounting world, which led me naturally into software development: first by automating repetitive work, then by designing increasingly complete systems, APIs, integrations, and internal tools.

Today, I'm working toward becoming a stronger software engineer through real projects and deliberate study.

## What I'm working with

* **C# / .NET** — APIs, services, desktop applications and automation
* **ASP.NET Core** — backend APIs and web services
* **Entity Framework Core** — data access and persistence
* **Python** — data processing, parsers and quick automation
* **JavaScript** — web applications and automation
* **SQL / PostgreSQL / SQLite / MySQL**
* **Git & GitHub**

## What I like building

I enjoy software that solves concrete problems:

* Automation tools
* APIs and integrations
* Data processing pipelines
* Internal business systems
* Fiscal/accounting software
* Desktop utilities
* Small tools that remove repetitive work

A lot of my projects start with:

> "There has to be a better way to do this."

Then I build it.

## Currently studying

I'm currently strengthening my foundations in:

* C# and the .NET ecosystem
* Object-oriented design
* Backend architecture
* Databases
* APIs
* Cloud deployment
* Software engineering practices

The goal is not just to make code work, but to understand **why the system works the way it does**.
